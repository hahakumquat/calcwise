## Specs for new items

Every spec: copy a neighbour calculator, add `examples` with the hand-checked values below, make FAQ answers match `compute()`, and keep the link to `related` calculators.

1. **Turkey time** (`food`). Inputs: weight (lb, with kg toggle), stuffed yes/no, oven 325 F, fresh or frozen-thawed, serve time. Formula: use the USDA FSIS roasting table at 325 F (unstuffed: 8-12 lb 2.75-3 h, 12-14 lb 3-3.75 h, 14-18 lb 3.75-4.25 h, 18-20 lb 4.25-4.5 h, 20-24 lb 4.5-5 h; copy the stuffed table from the same page, I only saw secondary charts, so verify every row). Output: cook-time range, start time = serve time - time - 30 min rest, and fridge thaw days = ceil(lb/5) to ceil(lb/4) (USDA: 24 h per 4-5 lb, verify). Safe temp 165 F (thigh, breast and stuffing). Example: 16 lb unstuffed -> 3.75-4.25 h; serve 17:00 with a 30-min rest -> out of the oven 16:30, so in the oven 12:15 (4.25 h) to 12:45 (3.75 h). Thaw 16 lb in the fridge -> 4 days (ceil(16/5)=4, ceil(16/4)=4). Sources: USDA FSIS "Roasting turkey" and "Big Bird" thawing pages.
2. **Stacked discounts** (improvement to `finance/discount`). Add: price, discount 1 %, extra discount 2 % (applied after), coupon $ off, sales tax %. Formula: price x (1-d1) x (1-d2) - coupon, then tax. Output: total off % = 1 - (1-d1)(1-d2). Example: $200, 30% then 20% -> $112.00, 44% off, not 50%. Add a social line "30% + 20% is 44%, not 50%".
3. **Gift budget** (`finance`). Inputs: total budget, fixed costs (travel, wrapping), adults, kids, kid weight (default 1.0, optional 1.5, note it is a rule of thumb from one site, not a standard), weeks left, optional already spent. Formula: per adult = (total - fixed) / (adults + kids x weight); per kid = per adult x weight; weekly saving = remaining / weeks. Example: $1,000, $200 fixed, 2 adults, 4 kids at 1.5 -> 800 / 8 = $100 per adult, $150 per kid. Benchmark NRF holiday figures only if linked to NRF itself (sources I saw disagree: $890 vs $628 gifts only).
4. **Savings challenge** (`finance`). Inputs: start amount, weekly increase, weeks (default 52), direction (up/down). Formula: sum of n terms = n/2 x (2a + (n-1)d). Example: $1 start, $1 step, 52 weeks -> $1,378; week 52 deposit $52. Chart: cumulative savings. Optional: add interest-free note.
5. **Rule of 72** (`finance`). Inputs: rate % or target years. Output: 72/rate years (approx) and exact ln 2 / ln(1+r). Example: 8% -> 9.0 years (exact 9.006); 6% -> 12 (exact 11.9). Say 72 is accurate for 6-10%.
6. **Subscription cost** (`finance`). Inputs: up to 10 rows (name, price, monthly/yearly/weekly). Formula: annual = monthly x 12, weekly x 52, yearly x 1. Optional: invest the savings at 7% for 10 years (annuity-immediate, assumption labelled). Example: $10 + $15 + $5 monthly -> $30/month, $360/year; a $120 yearly plan adds $120 -> $480/year, $40/month.
7. **Overtime pay** (`everyday`). Inputs: hourly rate, hours worked, weekly threshold 40, multiplier 1.5, optional holiday hours at 2x. Formula: regular = min(h,40) x rate; OT = max(h-40,0) x rate x mult. Example: $20, 48 h -> 800 + 8 x 30 = $1,040. Note state rules (e.g. daily overtime in CA) and link US DOL FLSA overtime page.
8. **Party food** (`food`). Inputs: guests (adults, kids), meal type. Formula: per-person amounts from a cited table (Butterball suggests about 1-1.5 lb of turkey per person, verify). Example: 10 guests x 1.5 lb -> 15 lb turkey. Add sides in a table; every constant must have a source before merge.
9. **Bill splitter** (`everyday`). Inputs: people with item subtotals, tax $ (or %), tip % (on pre-tax subtotal toggle). Formula: each person's share of tax and tip is proportional to subtotal. Example: A $30, B $20, C $50 (sum $100), tax $8, tip 20% of pre-tax = $20 -> total $128; A $38.40, B $25.60, C $64.00.
10. **Steps to distance** (`health`). Inputs: steps, height, sex. Formula: stride = height x 0.415 (men) or 0.413 (women), a common rule of thumb (cite and label as approximate). Example: 10,000 steps, 175 cm, male -> stride 72.6 cm, 7.26 km, 4.51 mi. Cross-link `calories-burned`.
11. **Plate calculator** (`sports`). Inputs: target weight, bar weight (45 lb or 20 kg), available plates, unit. Formula: per side = (target - bar)/2, greedy from largest plate; flag if not exact. Example: 225 lb, 45 lb bar -> 90 per side = 2 x 45. 135 lb -> 45 per side = one 45.
12. **Tax-loss harvesting** (`finance`). Inputs: realised gains this year, harvestable loss, filing status, ordinary and capital-gains rates.
